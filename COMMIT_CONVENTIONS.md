# Commit conventions

- Imperative mood: "Add X", "Fix Y", not "Added X" / "Fixes Y".
- One-line summary, under 70 characters, no trailing period.
- Body (optional) explains *why* the change was made, not what
  changed line-by-line — the diff already shows that.
- Reference specs/design docs by path when a commit implements one,
  e.g. `Implements specs/auth-flow.md`.
